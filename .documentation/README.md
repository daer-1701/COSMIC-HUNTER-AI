## Estado real del proyecto

- El usuario está evaluando/desarrollando el reto Planet X and SPHEREx de NASA Space Apps 2026.
- Se autoriza preparar documentación para compartir con el equipo; el stack y el alcance siguientes son propuestas, no decisiones confirmadas por el equipo.
- Al crear este paquete, el directorio del proyecto contenía únicamente `.git`.
- Se consultaron documentación y tutoriales. No se ejecutaron consultas de datos, descargas FITS, instalación de dependencias ni pruebas del prototipo.
- No están verificados cobertura de objetivos, cantidad de épocas útiles, latencias, credenciales, CORS ni disponibilidad operativa de cada servicio.
- El enlace oficial del reto respondió 502 al navegador de investigación. Los detalles específicos del reto se contrastaron con su reproducción en otra sede; el enunciado oficial prevalece.

## Resultado que buscamos — propuesta

Una web pública donde una persona introduce coordenadas del cielo y reproduce observaciones reales de SPHEREx en orden temporal para explorar posibles cambios. Primero demostrar una secuencia científicamente comparable; después ampliar interfaz y funciones.

No confundir una imagen bonita, una secuencia sintética o un cambio aparente con un descubrimiento validado.
