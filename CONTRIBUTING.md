# Contributing

Read README.md and docs/science.md. Use branches and small pull requests with
verification evidence. Do not introduce fabricated scientific data or credentials.
Distinguish prototypes, hypotheses, synthetic tests, and real results. Contract changes
require regenerating OpenAPI; persistent data changes require migrations. Run the
verification commands in the README. Document parameters, units, and scientific provenance.

Write documentation, comments, API messages, UI text, and project materials in English.
Preserve original source metadata and official names when recording evidence.
