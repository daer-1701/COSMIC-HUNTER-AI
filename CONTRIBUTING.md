# Contribuir

Leer README y docs/science.md. Trabajar por ramas y PRs pequeños con evidencia de
validación. No introducir datos científicos ficticios ni claves. Distinguir prototipo,
hipótesis, prueba sintética y resultado real. Cambios de contratos requieren regenerar
OpenAPI; cambios de datos persistentes requieren migración. Ejecutar los comandos de
verificación del README. Documentar parámetros, unidades y procedencia científica.
